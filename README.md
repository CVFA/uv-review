# uv-review
This is a small CLI written in Python that uses `uv` instead of `pip`, inspired by `pip-review`. This project also adds some extra features. I wrote it to solve my problem with outdated packages; however, this script lacks several features, and I am aware of that.

This CLI uses the `textual` library for the **interactive mode** TUI; you can install it with:
```bash
uv pip install “textual>=0.50” --system
```
